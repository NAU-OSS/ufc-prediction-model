# Code of Conduct

## Our Values

The UFC Prediction Model is meant to be an open and welcoming project where people can learn, contribute ideas, and improve the project together. Contributors should be respectful of different opinions, experience levels, and approaches to solving problems.

We value:

* Respectful and constructive communication.
* Collaboration and sharing ideas.
* Helpful feedback and discussion.
* Patience with new contributors.
* Keeping discussions focused on improving the project.

## Expected Behavior

Community members are expected to:

* Treat other contributors with respect.
* Give and accept constructive feedback.
* Explain disagreements without making them personal.
* Help new contributors when possible.
* Keep issues, pull requests, and discussions relevant to the project.
* Take responsibility for mistakes and work toward resolving problems.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, threats, or personal attacks.
* Insulting or intentionally disrespectful comments.
* Discriminatory or hateful language.
* Trolling or deliberately disrupting discussions.
* Sharing someone's private information without permission.
* Sexualized language or unwanted sexual attention.
* Repeatedly contacting contributors outside of normal project channels without permission.
* Any other behavior that would reasonably be considered inappropriate in a professional or collaborative environment.

## Where This Code Applies

This Code of Conduct applies to the project's GitHub repository, including issues, pull requests, discussions, and other project communication. It also applies when someone is publicly representing the UFC Prediction Model project or its community.

## Reporting a Violation

If you experience or witness behavior that violates this Code of Conduct, please report it privately to the project maintainer.

Reports should include as much information as possible about what happened, where it happened, and who was involved. Reports will be taken seriously and reviewed as fairly and privately as possible.

If the report involves the project maintainer, the reporter should contact another NAU OSS project administrator or maintainer instead.

## Enforcement

The project maintainer is responsible for reviewing reports and enforcing this Code of Conduct.

Depending on the situation, enforcement may include:

1. A private warning or request to change the behavior.
2. Removal of inappropriate comments or contributions.
3. Temporary restriction from participating in the project.
4. Permanent removal from the project for serious or repeated violations.

Enforcement decisions will consider the circumstances and seriousness of the behavior. The goal is to maintain a respectful and productive community rather than to punish people unnecessarily.

## Community Responsibility

Everyone who participates in this project helps shape its community. Contributors are encouraged to speak up when discussions become unproductive and to help create an environment where people feel comfortable asking questions, making mistakes, and learning.

Thank you for helping make the UFC Prediction Model a respectful and collaborative open-source project.
